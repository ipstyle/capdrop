# CapDrop

Screenshots in seconds, for macOS 14 and later. Free on the Mac App Store (coming soon).

[Deutsch](README.de.md) · [Website](https://ipstyle.github.io/capdrop/) · [Privacy](https://ipstyle.github.io/capdrop/privacy.html)

## Features
- Area, window, full screen, last area, timer, scrolling capture
- File names from your own pattern: date, time, app, window, counter, size
- Drop mode: press a key and the image is in the folder
- Editor: arrows, text, shapes, counter, blur, pixelate, crop, backgrounds, auto-redact
- Video and GIF with sound, camera and visible clicks
- Text recognition on device, history with text search
- Every feature gets its own shortcut

## Privacy
No network access, no account, no data collected.
